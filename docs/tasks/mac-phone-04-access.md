# 4. Подключение личного телефона к Mac

Работай в проекте investment-portfolio с уже работающим macOS-приложением из задачи 3. Прочитай `CLAUDE.md`, проверь, как меню определяет готовность сервера и завершает его. Сделай в меню «Подключить телефон» и «Отключить доступ с телефона». Телефон будет открывать действующий Angular-интерфейс. Установка PWA — отдельная задача.

## Что сделать

- Сохрани API на `127.0.0.1`. Для личного HTTPS-адреса используй Tailscale Serve. Проверь актуальный CLI и поддерживаемый вариант клиента macOS по официальной документации. При отсутствии Tailscale или входа в сеть покажи короткие шаги для Mac и телефона. Локальная работа приложения должна быть доступна и без Tailscale.
- Отображай фактический HTTPS-адрес и QR-код после готовности сервера и настройки Serve. QR содержит адрес портфеля. Доступ определяется действующими правилами сети Tailscale. Учти, что широкое существующее разрешение продолжает действовать при добавлении узкого. Дай инструкцию по ограничению доступа владельцем и конкретную проверку разрешения и отказа. Интерфейс должен точно указывать, какие условия приложение смогло проверить. Публичная публикация через Funnel в эту задачу не входит.
- Управляй только созданным приложением маршрутом. Проверь конфликты с существующей конфигурацией Serve. Прекращай проксирование до освобождения локального порта. Выбери способ, при котором после сбоя, выхода или перезагрузки старый URL не начнёт показывать другой процесс на том же порту. Обработай отключение Tailscale и повторное подключение. Отключение доступа с телефона сохраняет локальную работу портфеля.

## Как принять

Проверь логику жизненного цикла и ошибок воспроизводимыми локальными тестами. При доступности тестовой сети проверь открытие с разрешённого телефона по Wi‑Fi и мобильному интернету, отказ постороннему участнику, отключение доступа и сохранность чужих маршрутов. После остановки сервера подними на освободившемся порту тестовую страницу и проверь, что прежняя ссылка портфеля её не показывает. Используй тестовый портфель и изолированную конфигурацию для экспериментов.

Верни ветку и коммит либо состояние diff, инструкции первого подключения и отключения, команды проверок и результаты. Отдели тесты с подменённым CLI от реальной проверки на Mac и телефоне. Если для ручного шага нужен владелец сети, укажи точное действие и ожидаемый результат. Исключи токены и личные адреса из отчёта.
